# stream-subtitles

긴 영어 방송 다시보기 영상의 자동 자막을 문장 단위 한국어 자막으로 바꾸는 서비스입니다.

## 상태

서버와 확장 프로그램 최소 버전이 있습니다. 확장 프로그램이 유튜브의 자막 원본을 서버로 보내면, 서버가 문장 단위로 다시 묶어 5분 구간마다 번역하고 끝난 구간부터 저장합니다. 보고 있는 위치의 구간을 먼저 번역하므로 영상 전체를 기다리지 않습니다. 확장 프로그램은 번역된 부분부터 영상 위에 띄웁니다. 비용 상한과 인증은 아직 없고 배포하지 않았습니다. 서버는 이 컴퓨터에서만 접속됩니다.

이름과 용어는 용어집으로 맞춥니다. 손으로 쓴 용어집(`server/src/main/resources/glossary.json`)이 있고, 번역하는 동안 다른 모델이 영상의 자막 일부를 읽어 용어를 뽑아 채널별로 저장합니다. 뽑기를 기다리지 않고 번역을 시작하므로, 새 용어는 뽑기가 끝난 뒤에 시작하는 구간과 같은 채널의 다음 영상부터 쓰입니다. 손으로 쓴 항목이 우선합니다. 용어는 모델에게 맡기지 않고 서버가 자막 줄에서 미리 바꿔 넣습니다.

## 실행

Java 21과 Docker가 필요합니다.

```sh
cd server
./gradlew test                       # 테스트. PostgreSQL 컨테이너를 잠깐 띄웁니다
docker compose up -d                 # 로컬 DB (이 컴퓨터의 5433 포트)
ANTHROPIC_API_KEY=... ./gradlew bootRun   # 서버 (127.0.0.1:8787)
```

확장 프로그램은 Node.js가 필요합니다.

```sh
cd extension
npm install && npm run build
```

그다음 크롬의 `chrome://extensions`에서 개발자 모드를 켜고 "압축해제된 확장 프로그램을 로드합니다"로 `extension` 폴더를 고릅니다. 서버가 떠 있는 상태에서 영어 자동 자막이 있는 유튜브 영상을 열고 확장 프로그램 아이콘을 누르면 번역을 요청하고, 보고 있는 위치부터 자막이 뜹니다. 한 번 번역한 영상은 누르지 않아도 뜹니다.

| 요청 | 하는 일 |
|---|---|
| `POST /api/videos/{영상 번호}/translation?positionMs=` | 자막 원본(json3의 events)을 받아 번역을 시작합니다. 이미 처리했거나 처리 중이면 새로 시작하지 않습니다. 실패했거나 재시작으로 끊긴 영상은 빠진 구간만 번역합니다 |
| `GET /api/videos/{영상 번호}/subtitles?positionMs=` | 처리 상태와 지금까지 저장된 자막을 돌려줍니다. 번역 중이면 `positionMs`의 구간을 다음 차례로 올립니다 |

`eval/`에는 평가 구간 목록, 결함을 세는 스크립트, 자막이 뜰 때까지의 시간을 재는 스크립트, 용어 목록 초안이 있습니다. 자막 원자료(`eval/raw/`)는 남의 방송 자막이라 저장소에 올리지 않습니다.

## 풀려는 문제

- 자동 자막은 시간 단위로 끊겨서 문장 중간에서 줄이 나뉩니다. 줄마다 따로 번역하면 조각난 번역이 나옵니다.
- 번역 말투가 줄마다 바뀝니다.
- 채널과 게임의 고유 용어가 틀리게 번역됩니다.
- 여러 사람이 말하는 영상에서 두 사람의 말이 한 줄에 섞입니다.

## 구성 (예정)

| 부분 | 역할 |
|---|---|
| 크롬 확장 프로그램 (TypeScript) | 브라우저에서 자막 원본을 읽어 서버로 보내고 결과를 영상 위에 띄웁니다 |
| 서버 (Java, Spring Boot) | 문장 재구성, 번역 작업 처리, 용어집, 저장, 비용 통제 |
| PostgreSQL | 번역 결과, 용어집, 작업 상태, 비용 기록 |

## 다루지 않는 것

생방송 실시간 번역, 멤버십 전용 영상, 영어 외 언어는 다루지 않습니다.
